A service carries three findings that are *not* the same question: change a setting was saved and nothing deployed it — needs somebody image the tag moved, so this is a build nobody replaced source a file under the service is newer than its container The table this replaced put them in one "Up to date" column behind an if/elif chain, so `change` hid `image` and `image` hid `source`: a service could be all three and report one. `admin/test_status.py` opens by saying these must not collapse, and the page collapsed them anyway. So the three slots are always drawn, in the same order, whether or not anything hangs in them. An empty slot is a hairline; a full one is a solid tag. That costs space on a board where most circuits are clear — which is the point.
