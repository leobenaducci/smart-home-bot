Despliegue

Dónde corre, y qué se ejecuta. Las dos rutas son opcionales.

{# The script itself, not a path to one inside the repo. It never holds the password: the broker puts it in the environment when it runs this, so the script names the variable and the value is nowhere in the text. #}

Se ejecuta con sh -e dentro del proyecto cuando pedís desplegar, así que la primera línea que falle lo detiene. Nunca escribas una contraseña acá: la credencial llega como $DEPLOY_USER y $DEPLOY_PASSWORD, y su valor se borra de la salida. $DEPLOY_USER solo tiene valor con una credencial basic; con un token o una clave SSH viene vacío y la credencial entera está en $DEPLOY_PASSWORD. $DEPLOY_KIND dice cuál de las tres es y $DEPLOY_PROJECT, el proyecto. Pasásela a los programas por stdin o por archivo, como en el ejemplo — nunca como argumento, que cualquier proceso del host puede leer.
