{# The shell every config page wears. Four pages — Proyectos, Credenciales, Directorio, Correos — configure the same thing from different sides: what Alfred is allowed to know and do. They were four copies of one shell, 46 byte-identical CSS lines apiece, and they had already drifted once: the caret and the contrast tokens were fixed in two of them and not the other two, in the same afternoon. So the shell exists once. Nothing here is new design — it is the La Casa tokens and chrome the pages already shared, moved to the only place they can stay in agreement. The one idea this base adds is the `aside` block. Every one of these pages ends in an artifact somebody else reads: FAMILY.md for the directory, the config overlay for the mailboxes, a public key for a credential. A page that shows you the artifact is one you can check; a page that hides it is one you have to trust. Where a page has such a thing, it goes in the rail — same place, same monospace, same label — and where it does not, the rail is simply absent rather than filled with something invented for symmetry.
